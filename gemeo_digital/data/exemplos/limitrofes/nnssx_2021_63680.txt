PROJETO - NOME: Desenvolvimento de um equipamento de inspeção ótica (AOI)
DESCRIÇÂO: Esse projeto tem como elemento inovador o desenvolvimento de um equipamento automático para inspecionar a aparência de capacitores de filme plástico. Que deverão ser identificadas até 15 possíveis falhas conforme o padrão visual pré-definido assim como a qualidade da legibilidade da identificação impressa na peça.
Para o processamento das imagens será utilizada a tecnologia de machine learning. O algoritmo do machine learning se utiliza de imagens pré-classificadas como boas e ruins para desenvolver uma inteligência artificial e poder classificar novas peças durante o processo de inspeção. E após o escopo de projeto ocorreu o desenvolvimento do projeto mecânico utilizando software CAD para criar os melhores conceitos de alimentação, movimentação dos capacitores, posicionamento das câmeras em relação as peças e segregação, já para o desenvolvimento do sistema de visão se desenvolveu um protótipo impresso em impressora 3D para definir o melhor equipamento (câmera e iluminação) assim como seu posicionamento para se ter imagens para a criação do algoritmo de machine learning. O protótipo foi desenvolvido em conjunto com empresa parceira.
Neste ano, ocorreu a construção do equipamento conforme o projeto mecânico, entretanto na etapa de aprovação foram identificados alguns pontos que não permitiram o correto funcionamento do equipamento que tivemos que ajustar. Com bases nestes pontos, foi iniciado o reprojeto do equipamento, utilizando novos conceitos de alimentação e movimentação.
Para o ano de 2022, prevemos finalizar o reprojeto do equipamento, sua construção, instalação do sistema de visão e treinamento do algoritmo de machine learning.

PALAVRAS CHAVE: Sistema de visão; Inspeção óptica automática; Machine learning
ELEMENTO TECNOLÓGICO: Esse projeto tem como elemento inovador o desenvolvimento de um equipamento automático para inspecionar a aparência de capacitores de filme plástico. O equipamento deverá inspecionar as 6 faces do capacitor assim como seus terminais.
As falhas são geradas em decorrência dos processos anteriores (montagem, teste elétrico, marcação) devido a movimentação e erros de fabricação. Deverão ser identificadas até 15 possíveis falhas conforme o padrão visual pré-definido assim como a qualidade da legibilidade da identificação impressa na peça.
Atualmente as inspeções finais são realizadas manualmente pelas operadoras e a taxa de falha (peças ruins aprovadas) é aproximadamente 4,7 PPM (partes por milhão). O principal objetivo deste projeto é que não se tenha peças com falhas aprovadas.
Ao longo dos últimos anos foram introduzidos sistemas automáticos com câmeras como filtros intermediários, porém que não surtiram muito efeito na redução das falhas devido a limitação do posicionamento do capacitor na inspeção. O novo equipamento deverá permitir a manipulação das peças em diferentes ângulos e distancias de forma que as câmeras possam capturar imagens e distinguir e identificar as diferentes falhas.
Para o processamento das imagens será utilizada a tecnologia de machine learning. O algoritmo do machine learning se utiliza de imagens pré-classificadas como boas e ruins para desenvolver uma inteligência artificial e poder classificar novas peças durante o processo de inspeção.
Com base nas informações obtidas sobre machine learning aplicado em sistemas de visão viu-se que é possível aplicar esta tecnologia nos mais variados contextos. Em paralelo ao projeto principal, foi criado um grupo para verificar a aplicabilidade desta tecnologia em outros processos da TDK. Se verificou como potencial uso a inspeção do processo de soldagem de capacitores de filme.

DESAFIO TECNOLÓGICO: O principal desafio do projeto é garantir que nenhuma peça com falha seja aprovada e que gere risco de qualidade ao cliente. E por outro lado, o equipamento não pode gerar mais de 5% de quebra no processo (percentual de peças boas descartadas como falhas). Dentro do catálogo de falhas existem falhas relativamente pequenas (~0,1mm de diâmetro) que são difíceis de identificar devido ao seu pouco contraste e problema de desenvolver uma ferramenta de inspeção eficaz utilizando sistema convencionais de análise. Para estes casos utiliza-se os algoritmos de machine learning com uma grande quantidade de imagens de falhas para o treinamento do sistema.
O novo equipamento deverá ter um tempo de ciclo menor ou igual a 9 segundos e para isso será necessário o uso de 15 câmeras simultâneas. O desafio tecnológico neste aspecto é desenvolver uma arquitetura de processamento que permita atingir este nível de processamento em paralelo.
Outro desafio encontrado durante o desenvolver o projeto foi a criação de uma ventosa personalizada que conseguisse capturar a peça de menor dimensão (9,9mm X 3mm) e na superfície rugosa da marcação de forma estável para captura das imagens. Foram realizados testes com ventosas comerciais, porém o resultado não foi satisfatório, o posicionamento do capacitor variava durante sucessivos testes de captura.
O sistema atual de captura de peças que suportam altas velocidades de movimento é ineficaz e ineficiente. Isso ocorre porque as ventosas não conseguem segurar as peças por longos período de tempo. Por isto, é necessário desenvolver um novo sistema de captura de peças que suportem as altas velocidades de movimentação para superar este desafio.

METODOLOGIA: No ano de 2020, foi definido o escopo do projeto com os objetivos, premissas, restrições e riscos, realizado o desenvolvimento do caderno de especificação. Após as especificações iniciou-se o desenvolvimento do projeto mecânico utilizando software CAD e após isto, construído algumas amostrar para desenvolvimento do algoritmo de machine learning. Com isto, foi iniciado o processo de prototipagem do dispositivo de movimentação.
Para o ano atual, foi realizado a construção do equipamento seguindo as técnicas de gerenciamento de projetos, como cronograma para gerenciamento de tempo, gerenciamento de aquisições para compra de itens padrão, gerenciamento de riscos etc. Portanto, iniciamos com o escopo do projeto, etapa criada em conjunto com a engenharia de processo e produto, qualidade e produção onde analisamos as necessidades para a realização do projeto.
Após, foi realizado o caderno de especificação, etapa onde foram transcritas as necessidades do projeto em junto com as diretrizes da empresa para construção de novos equipamentos. E em seguida, foi iniciado o projeto mecânico do projeto, etapa de desenvolvimento do projeto com base no caderno de especificações e simulações de movimentos no software CAD com posterior detalhamento para construção.
Além disso, foi executado o desenvolvimento de inspeção do sistema de visão, desenvolvimento do conjunto de câmeras e iluminadores. Foi definido nesta etapa o uso de 14 câmeras operando em paralelo para atender o tempo de ciclo da máquina. Para a parte da lógica, se utilizou o software Adaptive Vision com o módulo de Machine Learning.
Em seguida, foi realizado o processo de aprovação do equipamento com testes. Este teste trata de um processo que utiliza peças padronizadas com defeitos conhecidos onde se espera que a máquina realize a correta classificação e segregação. Realizamos o teste com objetivo de identificar os problemas que pode ocorrer na hora que essas peças sejam utilizadas em um ambiente industrial. O teste não teve somente o objetivo de encontrar problemas, mas também aprender como as diferentes peças funcionam juntas como parte de um sistema. Ao identificar possíveis problemas, testes futuros podem ser projetados com mais eficiência, garantindo melhor resultados para todas as partes envolvidas.
Com base dos resultados dos testes, foram calculados os índices de eficácia de “bad in good” (peças ruins segregadas como aprovadas) e “good in bad” (peças boas segregadas como reprovadas). O índice é calculado através da razão entre o número de peças segregadas de forma correta e o número de peças totais que foram utilizadas no teste. É mandatório que ao final do projeto não se tenha peças com defeitos sendo aprovadas.
As atividades de construção, homologação e documentação da máquina estão previstas para 2022.

Qual a metodologia / métodos utilizados:
Durante o ano de 2020, para superar as barreiras do projeto, foi adotada uma metodologia que incluiu definir o escopo com objetivos, premissas, restrições e riscos, desenvolver um caderno de especificações e iniciar o projeto mecânico usando software CAD em colaboração com uma empresa parceira. Para validar o projeto, foram construídas amostras para desenvolvimento do algoritmo de machine learning, abrangendo todas as variações possíveis das falhas. O processo de prototipagem do dispositivo de movimentação também foi iniciado para o desenvolvimento do algoritmo de machine learning, usando um protótipo impresso em 3D em colaboração com a empresa parceira. No entanto, para o processo de soldagem, uma consulta ao fornecedor revelou a inviabilidade de utilizar a tecnologia de machine learning de forma confiável.
Para o ano de 2021, foi realizado a construção do equipamento seguindo as técnicas de gerenciamento de projetos, como cronograma para gerenciamento de tempo, gerenciamento de aquisições para compra de itens padrão, gerenciamento de riscos etc. Portanto, iniciamos com o escopo do projeto, etapa criada em conjunto com a engenharia de processo e produto, qualidade e produção onde analisamos as necessidades para a realização do projeto. Em seguida foi iniciado o projeto mecânico da máquina, utilizando como base o caderno de especificações e simulações de movimentos no software CAD, em reuniões multidisciplinares com todas as partes interessadas e o projetista foram definidas as soluções em cada componente da máquina para atender as premissas de projeto. Depois o projetista detalhou os desenhos mecânicos para que fosse possível construir as partes da máquina e posterior montagem. Em paralelo ao projeto mecânico foi desenvolvido um sistema de visão para inspeção com a definição do modelo das câmeras e iluminadores e posterior incorporação à máquina em conjunto com o software de inspeção desenvolvido no ano anterior.
Um sistema de visão é uma tecnologia que utiliza câmeras e iluminadores para capturar imagens de objetos ou peças em um processo de inspeção. Essas imagens são processadas por um software de inspeção para identificar defeitos ou características específicas das peças. No contexto do projeto, o sistema de visão foi implementado para inspecionar peças, melhorando o contraste das falhas e facilitando sua detecção e segregação adequada. O sistema de visão é uma parte integrante do processo de controle de qualidade, ajudando a garantir a conformidade das peças produzidas.
Durante o projeto do sistema de visão foi identificado um modo para melhorar o contraste das falhas, que era um dos desafios do projeto, ao implementar 2 iluminações trabalhando em paralelo em modo individual ou em par. Com isso facilitou a localização dos defeitos das peças e sua correta segregação.
Em modo individual, cada iluminação pode ser ajustada separadamente, permitindo um controle mais preciso sobre a intensidade, direção e temperatura de cor da luz emitida por cada fonte. Isso pode ajudar a realçar diferentes características ou defeitos na superfície da peça.
Em modo em par, as duas iluminações podem ser sincronizadas ou coordenadas de alguma forma para trabalhar juntas e produzir um efeito de iluminação combinado. Isso pode ser útil para criar um contraste mais forte ou destacar características específicas da peça.
Foi definido nesta etapa o uso de 14 câmeras operando em paralelo para atender o tempo de ciclo da máquina. Para a parte da lógica, se utilizou o software Adaptive Vision com o módulo de Machine Learning.
O uso de 14 câmeras operando em paralelo proporciona uma inspeção mais rápida, abrangente e confiável, garantindo uma alta qualidade e precisão no processo de controle de qualidade. Assim é possível capturar múltiplas imagens de diferentes partes da peça em um curto período de tempo, cobrir uma área maior da peça ou do objeto sendo inspecionado minuciosamente, oferecer uma maior redundância em caso de falha, e proporcionar uma maior flexibilidade e adaptabilidade no atendimento de diferentes condições de iluminação, ângulos de visão ou características específicas da peça.
O uso do módulo de Machine Learning no software Adaptive Vision adiciona uma camada de inteligência ao sistema de visão, permitindo que ele se adapte e melhore ao longo do tempo com base em novos dados e experiências. Isso aumenta a eficiência e a precisão da inspeção, contribuindo para um processo de controle de qualidade mais robusto e automatizado. Com módulo é possível treinar o sistema para que ele classifique cada vez melhor os defeitos, otimizar automaticamente os parâmetros do sistema de visão, como configurações de iluminação, filtros de imagem ou algoritmos de detecção de borda, e detectar novos padrões específicos nas imagens que indicam a presença ou ausência de características desejadas nas peças
Também, para superar o desafio tecnológico de processamento das imagens foi implementado um switch com fibra óptica para transferência das fotos e em conjunto foram utilizadas 2 placas de vídeo para comportar a capacidade necessária para executar o algoritmo.
Para transferir fotos, o switch com fibra óptica foi implementado para garantir uma conexão de alta velocidade e confiabilidade entre as câmeras do sistema de visão e o sistema de processamento de imagens. A fibra óptica oferece vantagens significativas em comparação com cabos de cobre tradicionais, como maior largura de banda, menor perda de sinal e imunidade a interferências eletromagnéticas. Isso resulta em transferências de dados mais rápidas e estáveis, o que foi chave para o processamento rápido e eficiente de imagens em tempo real no projeto.
Em seguida, foi realizado o processo de aprovação do equipamento com testes. Este teste trata de um processo que utiliza peças padronizadas com defeitos conhecidos onde se espera que a máquina realize a correta classificação e segregação. Realizamos o teste com objetivo de identificar os problemas que pode ocorrer na hora que essas peças sejam utilizadas em um ambiente industrial. O teste não teve somente o objetivo de encontrar problemas, mas também aprender como as diferentes peças funcionam juntas como parte de um sistema. Ao identificar possíveis problemas, testes futuros podem ser projetados com mais eficiência, garantindo melhor resultados para todas as partes envolvidas.
As principais dificuldades encontradas durantes os testes foram relacionadas ao sistema de visão e a correta identificação dos defeitos. Podemos citar a identificação da falha da superfície externa do produto suja com resina proveniente do processo de montagem pois a mesma é muito similar a superfície da caneca plástica do produto. Isso significa que o sistema de visão apresentou dificuldades em distinguir entre a sujeira e a parte normal da superfície da caneca, o que resultou em falsos positivos ou negativos na detecção de defeitos. Dessa forma, revisitamos tanto a parte física do sistema de visão quanto o algoritmo para que fosse possível realizar os ajustes necessários.
Outro problema identificado foi a presença de diferentes tipos de bolhas onde algumas não eram identificadas. Algumas bolhas foram mais difíceis de serem detectadas devido a suas características específicas, como tamanho muito pequeno e localização em áreas de difícil acesso, bem como pela presença de outras características na superfície das peças, como texturas irregulares ou padrões complexos. Além disso, o sistema não estava configurado o suficiente para identificar corretamente todos os tipos de bolhas. Para superar este desafio foi necessário subclassificar as bolhas para que o sistema reconhecesse todos os tipos.
Com base dos resultados dos testes, foram calculados os índices de eficácia de “bad in good” (peças ruins segregadas como aprovadas) e “good in bad” (peças boas segregadas como reprovadas). O índice é calculado através da razão entre o número de peças segregadas de forma correta e o número de peças totais que foram utilizadas no teste. É mandatório que ao final do projeto não se tenha peças com defeitos sendo aprovadas. As atividades de construção, homologação e documentação da máquina estão previstas para 2022. Portanto, as barreiras relacionadas a construção da máquina terão sua resolução apresentadas no próximo ano.

DO_CONTESTAÇÃO_JUSTIFICATIVA_PADRONIZADA - NOME: Caracterizou uma inovação sem ter sido resultado de P&D TITULO: No projeto nº <<NR_PROJETO>> CORPO: a empresa caracterizou uma inovação sem ter sido resultado de uma atividade de Pesquisa Básica Dirigida, Pesquisa Aplicada ou Desenvolvimento Experimental.A expressão “inovação” não pode ser utilizada de maneira absoluta, sem menção a um benchmarking ou outra forma de comparação que justifique a qualificação de inovação tecnológica. É importante ressaltar que o uso isolado da expressão inovação tecnológica como passível de benefício fiscal tem causado dificuldade no entendimento dos objetivos do Capítulo III da Lei do Bem. Não é a inovação em si que é objeto dos benefícios fiscais previstos na citada Lei e sim a pesquisa e o desenvolvimento tecnológico (pesquisa básica dirigida, pesquisa aplicada e desenvolvimento experimental), ou seja, atividades que buscam adquirir novos conhecimentos e onde ocorrem riscos tecnológicos, portanto, não se trata simplesmente de compra ou utilização nova tecnologia ou modernização tecnológica.  RODAPE: Dessa forma, o projeto apresentado não foi recomendado.
