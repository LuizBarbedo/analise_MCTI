PROJETO - NOME: SIM NEXT GEN
DESCRIÇÂO: "Escopo:
O projeto consiste de uma ferramenta de software para monitoramento e controle de dispositivos de segurança Intelbras, como DVRs, NVRs, Câmeras IP, seja local ou remotamente. Faz parte do objetivo o domínio da tecnologia, visando implementações futuras, bem como a possibilidade de integração de produtos de outros fornecedores e tecnologias experimentais. O software integra as linhas atuais de produtos de vídeo monitoramento da marca Intelbras. Foram aplicados novos conceitos de usabilidade, interface e experiência do usuário.
Durante o ano de 2020 identificamos novas necessidades do mercado e que foram incorporadas ao escopo do projeto:
•	Software multiplataforma (Windows, MacOS e Linux);
•	Interface amigável ao usuário, com design atual;
•	Melhoras no serviço de conexões com os dispositivos;
•	Integrações e disponibilização de recursos de busca forense para eventos.

Resultados esperados:
a) Com o SIM Next o usuário deverá poder visualizar suas câmeras em tempo real; acessar gravações remotamente; controlar saídas de alarme; alterar configurações dos dispositivos; buscar dispositivos automaticamente na rede.

b) O Sistema Inteligente de Monitoramento (SIM) é um software gratuito para o monitoramento de imagens, compatível com equipamentos de CFTV Intelbras. Além disso, deve ser compatível com sistema operacional Microsoft Windows® 10 e ter capacidade para mais de 1000 dispositivos, entre DVRs, NVRs e câmeras IP Intelbras. Deve suportar múltiplas telas de visualização, com até 64 câmeras em cada;

c) Deve permitir o uso da conta no Intelbras Guardian para migrar os dispositivos já cadastrados em outros aplicativos de monitoramento. Com o SIM Next deve ser possível gerenciar usuários por grupos, fazer configurações e backups remotamente, criar lista de dispositivos e realizar gravação local.
d) O sistema deve oferecer recursos para facilitar a busca de imagens e na investigação de eventos, permitindo que o usuário localize facilmente gravações relacionadas à eventos de alarmes registrados no software.
e) A pesquisa para desenvolvimento multiplataforma iniciada com base na arquitetura desenvolvida para o SIM Next será utilizada para iniciar um novo projeto, com início previsto em 2021, que possuirá uma interface de usuário amigável e poderá ser utilizado para gerar os pacotes de software para diversas plataformas e sistemas operacionais.
Descrição da etapa atual (2020):
1.	Adequação a LGPD:
Durante o ano de 2020 iniciamos a adequação do software para atendimento às restrições impostas pela LGPD.
Houve um extenso período de avaliação da legislação e impactos sobre o software, onde definimos critérios de segurança para garantir que o usuário do software possa ter gestão sobre as permissões de cada usuário, aumentando a segurança das informações armazenadas localmente e definimos a necessidade de autenticação da instalação do software vinculada a um usuário real, a fim de garantir que este tenha ciência e concordância com todos os dados que trafegam por nossos serviços e que possam ser armazenados ou utilizados pela Intelbras.

2.	Necessidade de um software com interface amigável e atualizada:
A necessidade por um software com interface mais amigável foi avaliada e iniciamos o desenvolvimento de uma nova interface para o software. Desenhamos as iterações com o usuário e definimos o escopo de recursos que esta persona específica necessita no software.

ELEMENTO TECNOLÓGICO: O Sistema Inteligente de Monitoramento – Intelbras SIM Next – é um software gratuito de supervisão de ambientes, desenvolvido para plataforma Windows, com foco principal no monitoramento de imagens. O software é compatível com equipamentos da Intelbras, oferecendo uma solução gratuita para monitoramento de ambientes, integrando solução de CFTV, alarme de intrusão e controle de acesso. É o primeiro produto da Intelbras nessa linha, com desenvolvimento interno, possibilitando o domínio da tecnologia para integrações posteriores

DESAFIO TECNOLÓGICO: "O desenvolvimento e integração de ferramentas de software que interagem com dispositivos eletrônicos é, via de regra, um trabalho complexo, devido as especificidades de cada equipamento, protocolos de comunicação, interação remota etc. Essas dificuldades aumentam significativamente quando esses dispositivos são produtos de segurança com suporte a vídeo, devido a inúmeras questões envolvendo vídeo streaming e armazenamento. Os principais desafios foram:

a) Desenvolver uma arquitetura de software rápida e estável para tratar com o volume de dados do tráfego de vídeo. Essa arquitetura deve ainda ser modular, que permita a integração de SDKs de múltiplos fabricantes, de forma a garantir que os usuários de produtos Intelbras possam utilizar um software único, independente do modelo de equipamento utilizado;

b) Criar uma interface do usuário que possibilite a integração de eventos de diversas fontes sem tornar o seu uso confuso;

c) Suporte à integração de Gravadores Digitais de Vídeo (DVRs) e Câmeras IP. Esses dispositivos utilizam protocolos de comunicação proprietários, nem sempre documentados de forma adequada, sem fluxo de sequência de mensagem claro e por vezes com inúmeros defeitos (bugs), dificultando o trabalho de integração e exigindo mais esforço do que geralmente se espera;

d) Conexão com os dispositivos. Quando o SIM Next roda em máquina que se encontra na mesma rede dos dispositivos a conexão é simples e direta. Entretanto, quando o SIM roda remoto o cenário muda bastante e a conexão com os dispositivos passa a requerer outra aplicação, desenhada especificamente para estabelecer o link com os dispositivos. No início, quando os dispositivos CFTV ganharam mercado, para que fosse possível o acesso remoto era necessário a intervenção de um técnico, que se deslocava até o local onde estavam os dispositivos e reconfigurava o roteador/firewall doméstico ou da empresa, liberando portas de acesso. Atualmente a figura do técnico não é mais necessária e uma mudança na estratégia de conexão permitiu que uma solução em nuvem cuidasse do processo de estabelecimento de comunicação de forma automática. Ao final, a simplicidade e comodidade para o consumidor só é conseguida por conta de uma complexa interação entre o SIM Next e a solução de estabelecimento de conexão;

e) Outro grande desafio se refere à compatibilidade com as diversas versões do sistema operacional e hardwares (máquinas) existentes no mercado. Os clientes que usam o SIM Next utilizam diversas versões do sistema operacional e, normalmente, computadores antigos ou de baixo custo, para os quais precisamos oferecer uma única distribuição do software;

f) Suporte a saídas de alarme Multibox. Recentemente o marketing Intelbras identificou espaço no mercado para uma solução que permitisse a integração dos dispositivos CFTV com outros produtos relacionados com segurança, como portões, sensores etc. Multibox é um produto Intelbras que disponibiliza um conjunto de saídas, que permitem comandar outros produtos; e entradas, que possibilitam a conexão com sensores. A integração do Multibox com o SIM Next é mais um exemplo de desafio tecnológico;

g) Desenvolvimento dos algoritmos de IVS, com base em redes neurais e machine learning, para detecção de face, LPR etc. Os algoritmos de análise de vídeo presentes em câmeras e DVRs, que no passado conseguiam apenas detectar se havia movimento em uma cena ou se determinada linha imaginária havia sido cruzada, evoluíram e atualmente conseguem executar funções complexas como a detecção de face, identificação de placas de automóveis (LPR), identificação de objetos etc. A integração dessas tecnologias no SIM Next tem sido outro grande esforço;

h) Gravação local. Essa é outra função adicionada ao SIM Next. Com ela é possível efetuar a gravação dos arquivos de vídeo na própria máquina onde está instalado, funcionando como um backup, uma alternativa à gravação existente nos DVRs. O suporte a essa função não é algo simples, devido ao enor

CONTESTAÇÃO APRESENTADA PELA EMPRESA: O projeto “SIM NEXT” é a concepção de um software desktop para o monitoramento de imagens compatíveis com os equipamentos de CFTV da Intelbras podendo ser utilizado em diferentes sistemas operacionais, como em Windows, MacOS e Linux. Além disso o software permite não apenas o monitoramento como também o gerenciamento de dispositivos permitindo a realização de gravações das imagens, o que possibilita o armazenamento local, além de ações que podem ser configuradas no software realizando o comando para os dispositivos a ele conectados, como por exemplo, um comando a um disposto de alarme quando existe uma detecção em algum ponto da imagem de uma câmera.

Como elemento novo ou inovador, o projeto em si é uma inovação para empresa pois se trata de um desenvolvimento de software exclusivo pela Intelbras através de uma pesquisa aplicada decorrente de uma necessidade de complementar uma melhor interação do usuário com os produtos físicos da linha de negócio de CFTV da empresa. Por se tratar de um software, também teremos inovações incrementais em relação ao projeto inicial, já que se trata de um desenvolvimento continuo e de constante melhoria, visando sempre a melhor experiencia do usuário.

Em termos de barreira ou desafio tecnológico a ser superável, o desenvolvimento e integração de ferramentas de software que interagem com dispositivos eletrônicos é, via de regra, um trabalho complexo, devido as especificidades de cada equipamento, protocolos de comunicação, interação remota etc. Essas dificuldades aumentam significativamente quando esses dispositivos são produtos de segurança com suporte a vídeo, devido a inúmeras questões envolvendo vídeo streaming e armazenamento. Os principais desafios foram:
a) Desenvolver uma arquitetura de software rápida e estável para tratar com o volume de dados do tráfego de vídeo. Essa arquitetura deve ainda ser modular, que permita a integração de SDKs de múltiplos fabricantes, de forma a garantir que os usuários de produtos Intelbras possam utilizar um software único, independente do modelo de equipamento utilizado;
b) Criar uma interface do usuário que possibilite a integração de eventos de diversas fontes sem tornar o seu uso confuso;
c) Suporte à integração de Gravadores Digitais de Vídeo (DVRs) e Câmeras IP. Esses dispositivos utilizam protocolos de comunicação proprietários, nem sempre documentados de forma adequada, sem fluxo de sequência de mensagem claro e por vezes com inúmeros defeitos (bugs), dificultando o trabalho de integração e exigindo mais esforço do que geralmente se espera;
d) Conexão com os dispositivos. Quando o SIM Next roda em máquina que se encontra na mesma rede dos dispositivos a conexão é simples e direta. Entretanto, quando o SIM roda remoto o cenário muda bastante e a conexão com os dispositivos passa a requerer outra aplicação, desenhada especificamente para estabelecer o link com os dispositivos. No início, quando os dispositivos CFTV ganharam mercado, para que fosse possível o acesso remoto era necessário a intervenção de um técnico, que se deslocava até o local onde estavam os dispositivos e reconfigurava o roteador/firewall doméstico ou da empresa, liberando portas de acesso. Atualmente a figura do técnico não é mais necessária e uma mudança na estratégia de conexão permitiu que uma solução em nuvem cuidasse do processo de estabelecimento de comunicação de forma automática. Ao final, a simplicidade e comodidade para o consumidor só é conseguida por conta de uma complexa interação entre o SIM Next e a solução de estabelecimento de conexão;
e) Outro grande desafio se refere à compatibilidade com as diversas versões do sistema operacional e hardwares (máquinas) existentes no mercado. Os clientes que usam o SIM Next utilizam diversas versões do sistema operacional e, normalmente, computadores antigos ou de baixo custo, para os quais precisamos oferecer uma única distribuição do software;
f) Suporte a saídas de alarme Multibox. Recentemente o marketing Intelbras identificou espaço no mercado para uma solução que permitisse a integração dos dispositivos CFTV com outros produtos relacionados com segurança, como portões, sensores etc. Multibox é um produto Intelbras que disponibiliza um conjunto de saídas, que permitem comandar outros produtos; e entradas, que possibilitam a conexão com sensores. A integração do Multibox com o SIM Next é mais um exemplo de desafio tecnológico;
g) Desenvolvimento dos algoritmos de IVS, com base em redes neurais e machine learning, para detecção de face, LPR etc. Os algoritmos de análise de vídeo presentes em câmeras e DVRs, que no passado conseguiam apenas detectar se havia movimento em uma cena ou se determinada linha imaginária havia sido cruzada, evoluíram e atualmente conseguem executar funções complexas como a detecção de face, identificação de placas de automóveis (LPR), identificação de objetos etc. A integração dessas tecnologias no SIM Next tem sido outro grande esforço;

Todos esses são de fato desafios que devem ser compreendidos durante o desenvolvimento do projeto.

?	Criação de lista de ações a serem executadas a partir de evento de alarme ou IVS;
