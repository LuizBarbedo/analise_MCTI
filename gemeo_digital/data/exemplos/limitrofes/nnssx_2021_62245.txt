PROJETO - NOME: 310700104-Desenvolvimento de software para integrar os programas de cálculo elétrico ASYN e OTM4E
DESCRIÇÂO: Serão criados quatro documentos com relações DE-PARA indicando as conversões entre os dados de entrada do cálculo ASYN para o OTM4E e vice-versa, sendo dois referentes à motores trifásicos de baixa tensão e outros dois de alta tensão. Estes documentos servirão de referência para a criação do novo software que fará a integração automática dos dados. A conversão de um cálculo para outro se faz necessária porque os programas ASYN e OTM4E têm diferentes rotinas para aplicações específicas. Por exemplo, apenas no ASYN é possível avaliar termicamente um motor da linha W60, porém se for necessário avaliar o desempenho desse mesmo motor com inversor de frequência, ele terá que ser rodado no OTM4E. A transferência dos dados de entrada realizada manualmente além da baixa produtividade, pode comprometer totalmente o resultado esperado caso algum dado seja erroneamente digitado.

PALAVRAS CHAVE: ASYN; OTM4E; integração
ELEMENTO TECNOLÓGICO: Os programas de cálculo ASYN e OTM4E rodam em diferentes interfaces, o primeiro no NEWTON WEN e o segundo no NEWTON WMO. Atualmente a transferência de dados é totalmente manual, podendo levar a erros. Propõe-se criar um programa capaz de fazer a conversão automática entre os dados de entrada de um cálculo para outro. Para isso precisamos estudar ambos programas de cálculo para entender a relação entre os dados de entrada de um e do outro programa, fazendo as conversões necessárias. Por exemplo, as dimensões das ranhuras de estator e rotor são informadas de diferentes maneiras num e noutro programa, precisando em alguns casos até mesmo fazer adaptações.

DESAFIO TECNOLÓGICO: Durante o desenvolvimento do projeto precisaremos entender as diferentes formas de entrada de dados dos programas ASYN e OTM4E para as variáveis de cálculo em comum, isso porque cada cálculo tem diferentes variáveis para representar determinados parâmetros de entrada. Por exemplo, os dados dimensionais das ranhuras de estator e rotor são representados no ASYN a partir de tipos padrões de ranhuras enquanto que no OTM4E as dimensões se referem a uma ranhura genérica capaz de representar qualquer tipo de ranhura. Outro desafio será definir as variáveis de entrada não comuns para os dois cálculos, por exemplo, modelo e letra da carcaça são dados de entrada do ASYN mas não disponíveis no OTM4E.

METODOLOGIA: 1) Estudar os cálculos ASYN e OTM4E para conhecer como as variáveis de entrada de um estão relacionadas com a do outro para assim poder realizar as devidas conversões. 2) Desenvolver documentos DE-PARA indicando as conversões necessárias para as variáveis de entrada nas condições de baixa e alta tensão, do ASYN para o OTM4E e vice-versa. 3) Programar as lógicas de conversão diretamente no sistema NEWTON, facilitando assim as integrações entre as variáveis de entrada de um e de outro. 4) Realizar diversas conversões entre os cálculos ASYN e OTM4E para validação dos resultados.

CONTESTAÇÃO APRESENTADA PELA EMPRESA: Projeto n° 159
Conforme mencionado no Parecer Técnico, este projeto não atendeu aos requisitos legais para ser considerado como atividade de PD&I, neste sentido apresentamos abaixo fundamentos adicionais e até mesmo melhor caracterização da Descrição do Projeto, Elemento tecnologicamente novo ou inovador, Barreira ou Desafio Tecnológico Superável e Metodologia / métodos utilizados a fim de prover à equipe técnica do MCTI maior associação da atividade proposta com elementos de PD&I.

Elemento tecnologicamente novo ou inovador:
O projeto em questão é focado no desenvolvimento de um software inovador, destinado a aprimorar a interoperabilidade entre dois sistemas de cálculo utilizados na engenharia de motores elétricos na WEG Motores: o OTM4E e o ASYN. Esses sistemas são fundamentais para a análise e desenvolvimento de motores, mas a necessidade de alternância entre eles, devido às especificidades das análises requeridas, introduziu um desafio considerável: a conversão manual de dados. Esta prática não é apenas onerosa em termos de tempo dedicado pelos especialistas, mas também está intrinsecamente vulnerável a erros e inconsistências, podendo resultar em retrabalho extensivo e potencial falha em atender às expectativas dos clientes e aos padrões de qualidade do mercado.

Antes deste projeto, a transferência de dados entre o OTM4E e o ASYN era um processo manual oneroso. Os especialistas são confrontados com a tarefa de converter dados entre formatos distintos, um processo que não é apenas propenso a erro devido à complexidade dos dados, mas também representa um gargalo significativo na eficiência operacional. No cenário em que o especialista tenha cometido erros de conversão é possível que leve a um retrabalho que se propagará para a cadeia de criação do produto, além de ocasionar no não atendimento de alguma das especificações esperadas pelo cliente e normas vigentes, fazendo com que esta ação seja muito crítica.

O software proposto neste projeto busca eliminar esses problemas criando a automatização da transferência e conversão de dados entre os sistemas de cálculo. A inovação central do software reside na sua capacidade de compreender e transformar as diversas maneiras pelas quais os dados são apresentados pelos dois sistemas. Isso exige não apenas um entendimento profundo das estruturas de dados subjacentes a ambos os programas, mas também o desenvolvimento de algoritmos capazes de interpretar e converter dados de maneira eficaz e precisa, sem a necessidade de intervenção manual.

Como o projeto contempla a criação de uma espécie de middleware que possa facilitar a comunicação entre os dois sistemas, agindo como um tradutor de dado ele não apenas resolverá o problema imediato de interoperabilidade, mas também estabelecerá uma infraestrutura que pode ser adaptada para futuras integrações de sistemas similares.

Além de trazer um ganho significativo na eficiência operacional, o desenvolvimento desse software contribui para um expandir os conhecimentos pela equipe envolvida no projeto. A necessidade de entender profundamente as complexidades dos dois sistemas de cálculo e de criar algoritmos inovadores que possam realizar as conversões necessárias desafiará a equipe a explorar novas fronteiras em ciência de dados e engenharia de software.

Barreira ou Desafio Tecnológico Superável:
A interoperabilidade entre os programas ASYN e OTM4E representa um problema tecnológico significativo dentro deste projeto, exigindo uma abordagem inovadora para permitir a comunicação eficaz entre estes sistemas distintos. Estes programas são utilizados para cálculos de engenharia precisos, mas operam com conjuntos de dados estruturados de maneira diferente. A principal barreira tecnológica a ser superada é a capacidade de traduzir e converter dados entre estes sistemas de forma eficaz, de modo a permitir uma análise integrada e coerente e que todo esse processamento seja executado de maneira mais eficiente e dinâmica possível.

Como ambos os softwares de cálculos são proprietários da WEG e desenvolvidos internamente, a conversão entre os dados também necessita ser desenvolvida internamente pois não é conhecido algum software do mercado que realize essas conversões de maneira direta e simplificada.

As dificuldades e desafios tecnológicos envolvidos neste projeto são multifacetados. Há o desafio de mapear com precisão as variáveis de cálculo comuns e não comuns entre os dois sistemas, o que requer uma compreensão detalhada de ambos os programas. Por exemplo, a representação das dimensões das ranhuras do estator e do rotor é abordada de maneira divergente entre os programas: o ASYN utiliza tipos padrões de ranhuras, enquanto o OTM4E adota um modelo mais flexível com ranhuras genéricas. Outra dificuldade é que os softwares tratam de maneiras muito diferentes as dimensões de bobinas pré-formadas e suas dimensões o que exige um estudo aprofundado.

Metodologia / métodos utilizados:
O desenvolvimento deste trabalho baseia-se em realizar um estudo sobre as variáveis de ambos os sistemas e compreensão da física das variáveis através de referências e análise de bancos de dados. Isso permite que sejam levantados os possíveis algoritmos que possam ser utilizados na conversão levando a implementação do software e testes. Sendo assim, a equipe adotará a metodologia detalhada a seguir:

1.Estudo: Análise detalhada dos cálculos ASYN e OTM4E para mapear a inter-relação entre suas variáveis de entrada, estabelecendo uma compreensão da dinâmica entre os dois sistemas e identificando as possíveis conversões.
2.Levantamento de algoritmos: Elaboração de documentos de correspondência, que delineiam as conversões precisas para as variáveis de entrada sob condições de baixa e alta tensão, possibilitando uma transição de dados do ASYN para o OTM4E e que o mesmo ocorra reciprocamente.
3.Implementação: Realizar a criação de algoritmos de conversão no software, otimizando o processo de integração e garantindo a coerência entre as variáveis de entrada dos cálculos ASYN e OTM4E.
4.Teste: Execução de uma série de conversões teste entre os cálculos, com o intuito de validar a precisão e a confiabilidade dos procedimentos e resultados obtidos, assegurando a efetividade das soluções desenvolvidas.

Descrição do Projeto:
O projeto em questão visa superar desafios tecnológicos relacionados à interoperabilidade entre dois sistemas distintos de cálculo utilizados na avaliação de motores elétricos: ASYN e OTM4E. Esta barreira tecnológica resulta em uma transferência manual de dados entre os sistemas, que não só é propensa a erros, mas também ineficiente, afetando adversamente a precisão dos resultados e a produtividade geral. Portanto, o objetivo principal deste projeto é desenvolver um software inovador que possibilite a integração automática dos dados entre os sistemas ASYN e OTM4E, superando os desafios de interoperabilidade.

A justificativa para a realização deste projeto baseia-se em sua capacidade de transformar o processo de avaliação de motores elétricos, tornando-o mais preciso, eficiente e menos suscetível a erros humanos, aumentando também a competitividade de mercado e conhecimento sobre as tecnologias de cálculo de motores elétricos.

Os resultados desejados ao final do projeto incluem a implementação bem-sucedida do software de integração, que resultará em um aumento significativo na precisão e eficiência da avaliação de motores elétricos. Espera-se também uma redução nos custos operacionais associados à avaliação manual e uma melhoria na tomada de decisões relacionadas ao desenvolvimento de produtos.

As vantagens deste projeto são numerosas. Além de aumentar a precisão e eficiência, o novo software promete reduzir o potencial de erros humanos, diminuir os custos operacionais e melhorar significativamente a competitividade no mercado. Adicionalmente, a automação do processo de transferência de dados contribui para a sustentabilidade ambiental, reduzindo a necessidade de recursos físicos e diminuindo a pegada de carbono associada às operações manuais.

No entanto, se o projeto não for bem-sucedido, enfrentaremos várias consequências negativas. O risco mais significativo é a perda de competitividade no mercado devido à incapacidade de melhorar a eficiência e precisão na avaliação de motores elétricos. Isso pode levar a decisões de desenvolvimento de produto mal-informadas, afetando adversamente a reputação e a viabilidade financeira da empresa.

Desta forma, solicitamos ao MCTI reconsideração deste projeto, bem como os valores envolvidos, reconhecendo o enquadramento como atividade de PD&I.
