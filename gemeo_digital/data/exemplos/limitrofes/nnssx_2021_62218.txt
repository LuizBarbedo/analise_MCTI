PROJETO - NOME: 310301018-Célula robotizada carga descarga usinagem da carc 160 200 
DESCRIÇÂO: Este projeto consiste no desenvolvimento de uma célula autônoma que possa substituir a forma atual do processo de usinagem de carcaças onde é necessário dois operadores, ou seja um operador para cada maquina de usinagem. A situação atual expõe o operador a riscos ergonômicos e de acidentes, bem como fadiga e ambiente com ruído.  O objetivo deste projeto é reduzir os riscos de acidentes e risco ergonômicos dos operadores devido a quantidade de manuseios e movimentos realizados pelo mesmo. Também haverá uma atualização tecnológica uma vez que o robô fará a integração com maquinas e dispositivos da célula. Este projeto se caracteriza pelo sistema que será desenvolvido para integrar máquinas existentes a um robô adquirido no mercado, proporcionando um fluxo continuo da linha sem interrupções. Esta demanda exigirá estudos e protótipos para desenvolvimento de dispositivos que garantam a correta fixação para manipulação das carcaças. Com a concretização deste projeto teremos uma redução de riscos de acidentes e doenças ocupacionais geradas em decorrência deste processo de fabricação.
PALAVRAS CHAVE: Célula robotizada; Usinagem; Robô
ELEMENTO TECNOLÓGICO: O elemento inovador neste projeto é o desenvolvimento de uma célula autônoma de usinagem contento duas maquinas de usinagem e um robô fazendo a  integração entre as maquinas de usinagem, ou seja o robô fara toda a parte de manipulação dos produtos a serem usinados e no final do processo o robô fara a paletização dos produtos. Atualmente as maquinas ficam em linha com um operador para cada máquina. Para o desenvolvimento deste projeto será necessário estudar o processo de usinagem, simulação de layout da célula para atender os tempos de produção, estudar a modificação dos dispositivos usado no processo para que atendam a integração com o robô.

DESAFIO TECNOLÓGICO: Os principais desafios deste projeto são: desenvolver a comunicação através de software de integração das maquinas com o robô evitando ao máximo a intervenção humana no processo; há também o desafio de desenvolver os dispositivos que fixam os produtos nas maquinas para que a usinagem possa atender toda a gama de produtos sem a intervenção humana. O principal desafio deste projeto é o desenvolvimento de um sistema de controle da célula, de modo que as operações sejam sincronizadas de modo que não existam paradas de máquina que prejudiquem a produtividade da linha.

METODOLOGIA: Instalação realizada na fábrica, alterando layout atual para atender o projeto. Desenvolvido software de integração do robô com as máquinas e testado ciclo com os equipamentos fazendo a usinagem das carcaças na célula robotizada. Realizado ajustes nos dispositivos das máquinas e nos métodos de usinagem, corrigindo parâmetros para obtenção do produto final. Desenvolvido novo componente para fixação das carcaças com material alternativo para garantir a movimentação das mesmas.

CONTESTAÇÃO APRESENTADA PELA EMPRESA: Projeto n° 132
Conforme mencionado no Parecer Técnico, este projeto não atendeu aos requisitos legais para ser considerado como atividade de PD&I, neste sentido apresentamos abaixo fundamentos adicionais e até mesmo melhor caracterização do Elemento tecnologicamente novo ou inovador, Barreira ou Desafio Tecnológico Superável e Metodologia / métodos utilizados a fim de prover à equipe técnica do MCTI maior associação da atividade proposta com elementos de PD&I.

Elemento tecnologicamente novo ou inovador:

O elemento inovador deste projeto é a pesquisa e desenvolvimento experimental de um processo autônomo de usinagem de carcaças de motores de tamanho 160 a 200mm. Atualmente este processo é realizado por meio de máquinas de usinagem alimentadas por operadores. As carcaças são dispostas em uma linha de roletes e os operadores realizam a movimentação delas da linha para as máquinas, devolvendo para a linha ao final das operações de usinagem.
No processo autônomo um robô deverá coletar as carcaças diretamente no pallet de transporte através de um sistema de visão que identificará a posição delas para correta manipulação entre as máquinas de usinagem, sistema de medição e ponto de descarga.
O processo proposto possui novidades tecnológicas referentes ao desenvolvimento de uma garra de robô para atender todos os tamanhos de carcaça garantindo a fixação e a precisão, sistema de visão capaz de identificar a posição da carcaça para evitar colisões, sistema de medição e regulagem automática do diâmetro usinado, além de detecção de quebra e desgaste de ferramentas de usinagem. Todas estas características permitiram desenvolver o processo autônomo.
Com as tecnologias disponíveis até então era possível automatizar algumas movimentações, porém com a necessidade de preparações, intervenção do operador e paradas do processo. A tecnologia desenvolvida possibilitou deslocar 4 operadores do processo produtivo, eliminando os riscos operacionais e ergonômicos, além de aumentar o percentual de utilização das máquinas de usinagem e a capacidade de produção, melhorando a performance do processo e a competitividade da empresa.
Além do visível aumento na qualidade e eficiência produtiva que possibilitou aumento da competitividade da empresa no mercado, o desenvolvimento este projeto também proporcionou ganho de conhecimento para a equipe WEG quanto aos temas sistemas de informação e sistemas de visão, bem como conhecimento para compreensão e desenvolvimento de processos de manufatura, gerando melhora nas habilidades técnicas e analíticas.

Barreira ou Desafio Tecnológico Superável:
Os principais desafios e barreiras foram encontradas no desenvolvimento do sistema de visão, garra do robô e sistema de comunicação entre as máquinas de usinagem e robô.

Para construção da garra do robô o desafio era que ela fosse única para todos os diâmetros de carcaça, sendo que estão envolvidas forças de fixação, inércia e precisão de posicionamento. Foram encontrados problemas nas primeiras versões de garras como escorregamento das carcaças e foram necessários testes com diferentes ângulos das cunhas e testes com materiais termoplásticos nas áreas de contato com a carcaça.
O sistema de visão se mostrou instável nos primeiros testes e foram instaladas proteções físicas e uma rotina de limpeza da base para garantir a estabilidade e funcionamento. Para a comunicação entre as máquinas de usinagem e o robô foram estudados os protocolos de comunicação disponíveis e desenvolvido internamente software de automação e controle do processo. Durante o período de testes foi necessária a instalação de diversos sensores não previstos no escopo para garantir a autonomia do processo e evitar paradas por eventos indesejados.

Metodologia / métodos utilizados:
Foi realizado um estudo das tecnologias atuais para processos autônomos de usinagem, sistemas de visão e sistemas de fixação e garras para robôs. Desenvolvidas pesquisas com fornecedores nacionais e internacionais para conhecimento das tecnologias existentes. Executado benchmark com outras áreas da empresa para levantamento das aplicações e processos existentes.
Foram executadas simulações de processo para determinação de tempos, movimentações, carga das máquinas e carga do robô, além de simulação estrutural para análise das forças de fixação aplicadas nos produtos. Com as informações levantadas foram desenvolvidos os softwares, algoritmos, projeto mecânico e sistemas necessários para comunicação entre as máquinas, robô e periféricos. Após a fabricação e montagens dos componentes foram iniciados os testes com os equipamentos e realizados os ajustes para resolução dos problemas encontrados, até a estabilidade do processo e instalação no ambiente produtivo.

Informação/Justificativa adicional:
Importante ressaltar que não existe no mercado uma solução pronta para este tipo de projeto, pois a usinagem da carcaça de motor é um processo específico de cada fabricante. Não havia certeza de que o projeto alcançaria o resultado esperado, pois se trata de um protótipo que é aperfeiçoado até o atingimento do resultado esperado, sendo que em alguns casos o projeto acaba sendo abortado ou implantado parcialmente. Neste caso os estudos, pesquisas, testes e conhecimento adquirido durante o desenvolvimento foram cruciais para o sucesso do projeto.

Desta forma, solicitamos ao MCTI reconsideração deste projeto, bem como os valores envolvidos, reconhecendo o enquadramento como atividade de PD&I.
