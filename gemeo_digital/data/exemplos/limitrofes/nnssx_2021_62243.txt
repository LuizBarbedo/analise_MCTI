PROJETO - NOME: 312600009-Detecção automática e predição de defeitos de estator em motores elétricos a partir da análise de dados do CTM e CTB.
DESCRIÇÂO: O projeto em questão é uma nova ferramenta de análise, para identificação e predição automática de defeitos de estator nos motores. Atualmente são realizados diversos ensaios que verificam se o motor está dentro do critério estabelecido pelo seu projeto. Quando um ensaio apresenta valor superior ao limite estabelecido, o motor é reprovado e encaminhado para análise.
Embora todos os motores que são produzidos sejam testados, ainda há casos em que o motor é aprovado, mas apresenta defeitos no estator em campo, o que corresponde ao maior índice de falha elétrica apresentado que é referente à 32,5% em motores comercias e 24,4% em motores industriais, de acordo com o QIS.
Dessa forma, o principal objetivo desse projeto é desenvolver um sistema que realize uma análise mais detalhada para aprovação do motor, que não sejam apenas os limites de engenharia estabelecidos.
Essa avaliação compreende a verificação do comportamento do material de determinado motor e estator como um todo, permitindo identificar a necessidade de realizar ajustes nos limites estabelecidos, e gerando também a correlação entre diferentes ensaios.
Com o desenvolvimento do projeto espera-se apresentar um software inteligente, capaz de identificar falhas no motor de forma automática e, ainda, predizer quando um motor pode vir a falhar, ainda que estando aprovado pelo critério dos limites de projeto.
PALAVRAS CHAVE: Defeito de estator; Cabine de Módulo de Teste; Identificação inteligente de falha; Predição de falha.
ELEMENTO TECNOLÓGICO: O elemento inovador está em propor uma estratégia para o melhor aproveitamento dos dados já coletados e armazenados nos ensaios dos painéis CTM e CTB, de modo que seja possível o desenvolvimento de um sistema inteligente para identificar falhas no estator ou, ainda, predizer possíveis falhas. Atualmente são realizados diferentes tipos de ensaios com o estator bobinado no CTB e com o motor montado no CTM. A aprovação do estator ou motor é dada baseada nos limites estabelecidos pela engenharia, na realização do projeto. No entanto, existem materiais que apresentam seus ensaios bem distantes desses valores limites, ou ainda, casos em que o motor aprovado apresentou defeitos para o cliente externo. Com uma análise crítica dos dados já armazenados é possível verificar a possibilidade de revisão desses limites, ajustando-os de forma a aumentar a confiabilidade do motor. Outro fator importante é que a partir do conhecimento do comportamento do material, torna-se possível desenvolver uma inteligência capaz de criar um critério de aprovação mais adequado e, ainda, predizer quando determinado material pode vir a dar problema, por meio de uma comparação com o seu histórico.

DESAFIO TECNOLÓGICO: O principal desafio é entender os dados que são armazenados e como utilizá-los. A análise inicial será correlacionando os dados de corrente no painel CTM e de resistência no painel CTB. Entretanto, havendo necessidade, outros ensaios serão adicionados aos dados analisados, com o objetivo de definir um sistema robusto de detecção automática e predição de falha. Devido à complexidade e diferentes possibilidades de se criar um conjunto de dados que forneça as informações suficientes para o desenvolvimento de um software completo, se faz necessário um estudo detalhado, a fim de que o projeto seja capaz de suprir as necessidades propostas.

METODOLOGIA: Etapa 1: uso da rotina desenvolvida em 2020 como base para desenvolver uma análise de lote dos ensaios de corrente do motor, comparando os valores obtidos com o histórico do respectivo material, para verificar se os ensaios do lote encontram-se dentro dos limites de controle do histórico, e também do próprio lote. O objetivo é conseguir identificar motores aprovados que podem vir a dar problema em campo, tendo como base motores que já deram problema.
Etapa 2: Estabelecer uma correlação de ensaios no CTM e no CTB para análise de indicativo de falhas. Inicialmente serão analisados os dados de corrente do CTM com os dados de resistência do CTB, considerando, se necessário, a utilização de outros ensaios que auxiliem na predição ou identificação de uma falha. A partir dessa análise será desenvolvida uma inteligência que seja capaz de fornecer informações sobre a confiabilidade do motor.

CONTESTAÇÃO APRESENTADA PELA EMPRESA: Projeto n° 157
Conforme mencionado no Parecer Técnico, este projeto não atendeu aos requisitos legais para ser considerado como atividade de PD&I, neste sentido apresentamos abaixo fundamentos adicionais e até mesmo melhor caracterização da Barreira ou Desafio Tecnológico Superável, a fim de prover à equipe técnica do MCTI maior associação da atividade proposta com elementos de PD&I.

Barreira ou Desafio Tecnológico Superável:
O principal desafio foi encontrar formas de processar a grande quantidade de dados dos testes armazenados entre os intervalos de produção nas fábricas, garantindo que as detecções de falhas fossem realizadas antes do envio para o estoque dos motores. Para uma avaliação dimensional, um motor é produzido a cada minuto em cada posto de teste, todos os dados dos painéis pilotos eram enviados para um mesmo local e deveriam ser separados e avaliados estatisticamente a tempo do motor ser rejeitado no posto seguinte (e esse tempo é diferente para cada local de painel instalado). A análise inicial foi correlacionando os dados de corrente no painel de montagem e de resistência no painel de bobinagem. Entretanto, houve a necessidade de adicionar outros dados aos dados analisados, com o objetivo de definir um sistema robusto de detecção automática e predição de falha, utilizando técnicas computacionais capazes de processar com eficiência todos esses dados. Devido à complexidade computacional e à necessidade de resgatar os testes realizados por requisição, a pesquisa foi direcionada para desenvolver um servidor conectado na rede interna. De início, o projeto modelo consistiu em uma arquitetura com escalabilidade vertical para o processamento e geração dos alertas para os técnicos responsáveis nas fábricas, enquanto definiu uma escalabilidade horizontal para o processamento contínuo dos dados. Dito isso, previu-se um estudo detalhado e dedicação em P&D para o desenvolvimento do projeto, a fim de que fosse capaz de suprir as necessidades propostas.

Desta forma, solicitamos ao MCTI reconsideração deste projeto, bem como os valores envolvidos, reconhecendo o enquadramento como atividade de PD&I.
