PROJETO - NOME: Desenvolvimento Cortado 3
DESCRIÇÂO: Uma das inovações desse projeto é prover a eliminação de caixas na movimentação de peças, desenvolver alimentação baseada em blister e desenvolver um equipamento no conceito linear de transporte de peças ao invés de mesa indexada como é usada na máquina atual. O objetivo é prover uma nova alimentação automatizada de capacitores axiais. Este tipo de capacitor demanda de alto número de operadores devido passar por muitas etapas especiais, tornando um produto com custo elevado para o cliente, gerando desvantagem competitiva com o mesmo produto fabricado em outros países. Ainda não existe uma solução pronta capaz de alimentar automaticamente este tipo de peça dentro das máquinas especiais (como é o caso desta máquina de corte), atualmente existe uma operadora para cada etapa de alimentação de peças.
Trata-se de um projeto multidisciplinar que envolve o desenvolvimento de tecnologias para diferentes partes da empresa garantindo que tudo funcione conforme o esperado. Será necessário desenvolver tecnologias de TI (software para gerar os códigos das etiquetas, desenvolver a impressora para elas), desenvolver um leitor de códigos que permita a leitura de todas as peças da caixa ao mesmo tempo, desenvolver o CLP do equipamento de modo a garantir que não seja fechada nenhuma caixa sem que seja efetuada esta leitura. Desenvolver sistema anti-burla para que a validação de rastreabilidade seja confiável.

PALAVRAS CHAVE: Automatização de processos, gravação de peças com laser para rastreabilidade, integração do processo com sistema de gestão de fábrica, indústria 4.0, blister.
ELEMENTO TECNOLÓGICO: Uma das inovações desse projeto é prover a eliminação de caixas na movimentação de peças, desenvolver alimentação baseada em blister e desenvolver um equipamento no conceito linear de transporte de peças ao invés de mesa indexada como é usada na máquina atual. O objetivo é prover uma nova alimentação automatizada de capacitores axiais. Este tipo de capacitor demanda de alto número de operadores devido passar por muitas etapas especiais, tornando um produto com custo elevado para o cliente, gerando uma desvantagem competitiva com o mesmo produto fabricado em outros países. Ainda não existe uma solução pronta capaz de alimentar automaticamente este tipo de peça dentro das máquinas especiais (como é o caso desta máquina de corte), atualmente existe uma operadora para cada etapa de alimentação de peças.
Além do processo automatizado foi implantada a rastreabilidade unitária de peças. Este projeto contempla uma solução para marcação a laser de um código data matrix permitindo a rastreabilidade peça a peça. Atualmente não é possível marcar peças cilíndricas com este tipo de laser.
Outro diferencial buscado pelo projeto é a incorporação de uma etapa de processo (teste elétrico InRush) dentro da máquina. Atualmente esse teste é feito em uma etapa apartada. Isso nos trará uma vantagem competitiva pela eliminação de uma etapa de processo.
Como elemento novo e inovador será possível adicionar etiqueta com código QR (peça-a-peça) para garantir que a peça passou pela etapa de teste elétrico. Iremos adicionar uma verificação antes de fechar a caixa para nos certificar de que não ocorram misturas.

DESAFIO TECNOLÓGICO: Desenvolver um sistema de alimentação confiável que não gere danos nas peças e não sobre nenhuma peça dentro do blister, foi um dos desafios deste projeto. Alterar todos os conjuntos que hoje são montados ao redor da mesa indexada, no sistema de transportador linear e aumentar o output da máquina (reduzir velocidade) em 25%, gerou dedicação da equipe de P&D para criar uma solução efetiva.
Outra dificuldade tecnológica é encontrar uma maneira de posicionar as peças que saem do forno de isolação da máquina de montagem M57, para uma bandeja com sistema embalador. Desta forma, será eliminada a causa de terminal torto devido à queda das peças, reduzindo a porcentagem de quebras. O novo sistema deve atender o ciclo da máquina e a geometria de todas as peças que são produzidas.
Trata-se de um projeto multidisciplinar que envolve o desenvolvimento de tecnologias para diferentes partes da empresa, e garantir que tudo funcione conforme o esperado. Será necessário desenvolver tecnologias de TI, software para gerar os códigos das etiquetas, desenvolver a impressora, desenvolver um leitor de códigos que permita a leitura de todas as peças da caixa ao mesmo tempo e desenvolver o CLP do equipamento de modo a garantir que não seja fechada nenhuma caixa sem que seja efetuado esta leitura. Outro desafio é desenvolver sistema anti-burla para que a validação de rastreabilidade seja confiável.

METODOLOGIA: No ano de 2020, foi realizado o desenvolvimento do sistema de alimentação, um blister flexível, realizado testes de protótipo, inspeções de peças e além disso, foi desenvolvido know-how sobre integração de banco de dados SQL com plataforma Twincat (beckoff), um know-how de programação de PC industrial utilizando orientação à objetos, um know-how sobre implantação de sistema de visão em rede profinet e uma integração de processos (CLP, sistema de gestão de fábrica MÊS e ERP SAP).
No ano de 2021 foi finalizada a construção do equipamento na Alemanha. Devido à situação da pandemia, o try-out precisou ser realizado de forma remota e o comissionamento da máquina aqui no Brasil também. O equipamento foi recebido, inspecionado e transportado para dentro de nossa fábrica onde foi instalado por nossa equipe. Algumas atividades foram desenvolvidas aqui no Brasil, aproveitando o know-how desenvolvido por nossa equipe: integração do equipamento de marcação à laser. Esse equipamento foi adicionado para realizar a gravação peça-a-peça de um código de rastreabilidade no produto, que terá seus dados de teste e inspeção com câmera armazenados em banco de dados. Outro conjunto que adicionamos aqui no Brasil, aproveitando o know-how de nossa equipe foi o dispositivo para teste de carga. Um teste elétrico que submete o componente à uma condição severa de aplicação de carga, para avaliar seu comportamento e segregar as peças suspeitas (que poderiam apresentar uma falha em campo, usando como método de avaliação o comportamento da curva de carga do componente). Uma série de testes de avaliações foram realizados no equipamento, durante o startup dele, e algumas modificações foram necessárias, especialmente no sistema de visão (inspeção dimensional com câmera), para tornar essa inspeção mais robusta e confiável. Peças padrão foram desenvolvidas tanto para validar o dispositivo de teste de carga quanto o sistema de visão. Foi adicionado na rotina operacional o teste com os padrões para conferir se o sistema está funcionando de acordo com o esperado. Seguiu-se a etapa de acompanhamento da produção (initial safe launch) e documentação, incluindo PFMEA, Plano de controle, padrão visual, manual de máquina, instrução de operação, e demais documentações técnicas (esquema elétrico, etc).
Um ponto em adicional que ocorreu ao longo do startup do equipamento, a observação de peças com o diâmetro externo da calota especial acima da especificação (no cliente). Essa calota possui dois diâmetros possíveis (dependendo do produto): Ø12mm e Ø13mm e é feita de alumínio puro (liga AW-1070EN, com 99,7% de alumínio em sua composição). Identificamos que o diâmetro fora da especificação era na verdade uma rebarba na borda dessa calota, gerada ao longo do processo de fabricação do capacitor, e portanto, não era gerada durante a etapa do processo em questão. Para solucionar esse problema, algumas alternativas/propostas foram sugeridas, das quais prototipações, desenhamos e confeccionamos. A alternativa escolhida foi realizar uma conformação à frio nessa calota, pressionando a mesma em sentido radial, considerando a natureza dúctil do alumínio. Dessa forma construímos a adicionamos a essa etapa do processo, a conformação da calota, o que viabilizou a produção desse capacitor em conformidade com as especificações técnicas do cliente. Essa etapa foi bastante desafiadora, considerando que a tolerância dimensional para a medida mencionada é de apenas ±0,015mm.

CONTESTAÇÃO APRESENTADA PELA EMPRESA: 4 – Desenvolvimento Cortado 3

Destaque o elemento tecnologicamente novo ou inovador da atividade:
Uma das inovações desse projeto é desenvolver uma nova solução, automatizada, para movimentação de peças, baseada na alimentação em blister, visando o desenvolvimento de um equipamento no conceito linear de transporte de peças ao invés de mesa indexada, como é usada na máquina atual, provendo assim uma nova alimentação automatizada de capacitores axiais. Desta forma, essa inovação proporcionará ao processo de movimentação de peças um evidente ganho em eficiência e rapidez. A empresa não possui uma solução capaz de alimentar automaticamente este tipo de peça dentro das máquinas especiais (como é o caso desta máquina de corte). Atualmente existe uma operadora para cada etapa de alimentação de peças. Além do processo automatizado, inovamos com a rastreabilidade unitária de peças. Assim, este projeto também contempla uma solução para marcação a laser de um código data matrix permitindo a rastreabilidade peça a peça. Atualmente não é possível marcar peças cilíndricas com este tipo de laser. Também inovaremos quanto a incorporação de uma etapa chave do processo (teste elétrico InRush) dentro da máquina. Atualmente esse teste é feito em uma etapa separada do processo. Isso nos trará otimização do processo, pois será possível incorporar a mesma nesta máquina. Além disso, esse projeto tem como elemento novo e inovador a adição do com código Qrcode (peça-a-peça) para garantir que a peça passou pela etapa de teste elétrico.

Qual a barreira ou desafio tecnológico superável:
Para que as inovações do projeto se concretizassem é necessário superar alguns desafios tecnológicos. Inicialmente, será necessário desenvolver um sistema de alimentação confiável. Assim, um dos desafios desse projeto é implementar essa automação sem causar danos as peças, e ao mesmo tempo, sem a possibilidade de sobrar peças dentro do blister.
Além disso, este projeto traz consigo um risco tecnológico associado à necessidade prevista de aumentar a velocidade do processo. A modificação de todos os conjuntos atualmente montados em torno da mesa indexada, requer a implementação de um sistema de transportador linear mais eficiente e que aumente a capacidade de produção da máquina. Desta forma, o desafio consiste no desenvolvimento de um transportador do capacitor que não inviabilize os processos de alinhamento, corte e inspeção dimensional, porque o capacitor não terá uma fixação através de garras como é feito nos equipamentos com mesa indexada.
Além disso, enfrentamos um desafio tecnológico adicional no processo de gravação do QR code em superfícies planas ou com raio de curvatura mais amplo a uma aplicação comum. A gravação em superfícies com raio pequeno (inferior a 15 mm) revela-se complexa para assegurar uma leitura precisa.
Por último, a implementação do teste de carga (In-rush) acarreta um risco no desenvolvimento tecnológico associado ao procedimento que administra uma corrente de 120A em cada capacitor. Este não é um processo trivial, especialmente ao considerarmos que será integrado ao equipamento de corte de terminais, levando em conta a configuração específica do transportador linear.

Qual a metodologia / métodos utilizados:
Em 2020 o projeto iniciou com o desenvolvimento do sistema de alimentação. Uma análise comparativa foi realizada usando um benchmark de conhecimento existente de outros projetos, incluindo alimentação manual peça a peça. No entanto, esse método mostrou-se pouco produtivo, levando à necessidade de pesquisa e desenvolvimento. Outra opção considerada foi o anyfeeder, um sistema com visão para identificar a posição dos capacitores e um robô para transporte. Contudo, havia o desafio de danificar os capacitores devido ao contato durante o processo. A solução foi criar um blister especial para acomodar os capacitores, com uma matriz de coordenadas para dois blisters e um sistema de "pega" em formato de prisma com ventosa incorporada. O projeto continuou com o desenvolvimento de um transportador linear que permitisse alinhamento, corte e inspeção dimensional, sem fixação dos capacitores. Variantes de prismas foram desenvolvidas para diferentes diâmetros, visando estabilidade. Posteriormente, o código QRCode foi gravado nos capacitores de 18 e 20 mm, com testes para determinar a receita ideal. Além disso, um equipamento especializado com conceito de mesa indexada foi concebido para o teste de In-rush, com extensivos testes de integração. Por fim, tivemos o desenvolvimento do prisma transportador, que permitiu uma maior estabilidade durante os movimentos, possibilitando a produção de diferentes dimensões e originando um sistema de medição usando cobre berílio.
Já no ano de 2021 foi finalizada a construção do equipamento na Alemanha. Devido à situação da pandemia, o try-out precisou ser realizado de forma remota através de vídeos mostrando o funcionamento do equipamento. Além disso, capacitores processados no equipamento foram enviados para avaliação na planta da TDK. Medições de concentricidade e alinhamento do fio, avaliação de marcas e danos no capacitor, bem como a medição das demais características dimensionais foram realizadas. O comissionamento da máquina aqui no Brasil também ocorreu remotamente. A máquina foi totalmente montada por equipe da TDK. Proteções, painel elétrico e cabeamentos, robôs, entre outros, foram todos montados conforme orientações passadas pelo fabricante. Os primeiros testes foram realizados por equipe da TDK com o suporte remoto do fabricante.
O equipamento foi recebido, inspecionado e transportado para dentro de nossa fábrica onde foi instalado por nossa equipe. Algumas atividades foram desenvolvidas aqui no Brasil, aproveitando o know-how desenvolvido por nossa equipe: integração do equipamento de marcação à laser.
Esse equipamento foi adicionado para realizar a gravação peça-a-peça de um código de rastreabilidade (QRCode, conforme mostrado na figura 6 do anexo) no produto. Para isto, toda a integração com o software do equipamento foi realizada, bem como a parametrização do equipamento de gravação, através de testes para determinar o foco, potência e tempo de gravação ideais para a aplicação.  Todos os dados de inspeção da peça (medições do sistema de visão e testes elétricos), são registrados no banco de dados da empresa e podem ser associados a cada capacitor através do código individual registrado no QRCode, garantindo rastreabilidade total do produto. Toda a integração do banco de dados com o equipamento foi realizada internamente.
Outro conjunto que adicionamos aqui no Brasil, aproveitando o know-how de nossa equipe foi o dispositivo para teste de carga. Um teste elétrico que submete o componente à uma condição severa de aplicação de carga, para avaliar seu comportamento e segregar as peças suspeitas (que poderiam apresentar uma falha em campo, usando como método de avaliação o comportamento da curva de carga do componente). O teste precisou ser adaptado para este equipamento. Como o teste trabalha com uma alta taxa de aquisição de dados, todo o cabeamento teve de ser recalculado conforme geometria do equipamento para evitar ruídos elétricos. O banco de resistores que determina a corrente aplicada teve de ser recalculado conforme a impedância do novo cabeamento. A integração do teste com o software da máquina foi feita internamente, bem como o registro dos resultados no banco de dados da empresa.
Uma série de testes de avaliações foram realizados no equipamento, durante o startup dele, e algumas modificações foram necessárias, especialmente no sistema de visão (inspeção dimensional com câmera), para tornar essa inspeção mais robusta e confiável. Dentre os principais testes, podemos citar:
Avaliação dos resultados apresentados pelo sistema de visão: Capacitores com medidas conformes e não conformes foram avaliados em equipamento de medição tridimensional e, posteriormente foram avaliados no sistema de visão implementado no equipamento para avaliar a acuracidade dos resultados. Foi verificado que a medição do diâmetro da calota do capacitor apresentava resultados com diferença significativa comparado com as medições do equipamento de laboratório (tridimensional). Baseado nestes resultados, o software do sistema de visão foi modificado para buscar maior precisão de medição.
Avaliação da eficiência do equipamento: Nos primeiros testes o equipamento demostrou uma baixa eficiência (~50%). O equipamento ficava metade do tempo produtivo inoperante devido a bugs de software e ineficiências do sistema mecânico. O software foi corrigido conforme os problemas foram aparecendo e algumas peças mecânicas foram retrabalhadas buscando um melhor funcionamento. Com todas as modificações a eficiência subiu para 80%.
Avaliação da capacidade de processo: Um lote de 2000 peças foi produzido e 125 peças aleatórias tiveram suas dimensões medidas e comparadas com a especificação do produto. Os dados foram avaliados matematicamente para a avaliar a capabilidade do processo.  A dimensão do terminal após cortado pelo equipamento não apresentou capabilidade conforme as normas da indústria automobilística. Para tornar o processo capaz, o sistema de indexação da peça no conjunto de corte foi reprojetado buscando um melhor posicionamento do capacitor no momento do corte.
Peças padrão foram desenvolvidas tanto para validar o dispositivo de teste de carga quanto o sistema de visão. Foi adicionado na rotina operacional o teste com os padrões para conferir se o sistema está funcionando de acordo com o esperado.
A peça padrão do teste de carga consiste em um capacitor com um circuito eletrônico acoplado que simula a falha de carga. Este circuito foi desenvolvido através de simulações de falha na máquina e comparadas com falhas reais, a fim de desenvolver uma peça padrão que simule uma falha real.
Para o sistema de visão, a peça padrão desenvolvida consiste em um gabarito usinado com as dimensões conhecidas para verificar se o sistema de visão mede os valores corretamente.
Um ponto em adicional que ocorreu ao longo do startup do equipamento, a observação de peças com o diâmetro externo da calota especial acima da especificação (no cliente). Essa calota possui dois diâmetros possíveis (dependendo do produto): Ø12mm e Ø13mm e é feita de alumínio puro (liga AW-1070EN, com 99,7% de alumínio em sua composição). Identificamos que o diâmetro fora da especificação era na verdade uma rebarba na borda dessa calota, gerada ao longo do processo de fabricação do capacitor, e portanto, não era gerada durante a etapa do processo em questão. Para solucionar esse problema, algumas alternativas/propostas foram sugeridas, das quais prototipações, desenhamos e confeccionamos. A alternativa escolhida foi realizar uma conformação à frio nessa calota, pressionando a mesma em sentido radial, considerando a natureza dúctil do alumínio. Dessa forma construímos a adicionamos a essa etapa do processo, a conformação da calota, o que viabilizou a produção desse capacitor em conformidade com as especificações técnicas do cliente. Essa etapa foi bastante desafiadora, considerando que a tolerância dimensional para a medida mencionada é de apenas ±0,015mm.
Por fim, o projeto seguiu com a etapa de acompanhamento da produção (initial safe launch) e documentação, incluindo PFMEA, Plano de controle, padrão visual, manual de máquina, instrução de operação, e demais documentações técnicas (esquema elétrico, etc). Estas documentações são requisitos da indústria automobilística para a liberação de um equipamento para produção.
Com os documentos concluídos, e os pontos de melhoria e desenvolvimento interno listados neste documento implementados, o equipamento foi liberado para produção. Desta forma, o projeto foi finalizado através do desenvolvimento completo da solução proposta.

É importante ressaltar que o uso isolado da expressão inovação tecnológica como passível de benefício fiscal tem causado dificuldade no entendimento dos objetivos do Capítulo III da Lei do Bem. A alteração ou criação de um produto ou processo podem ser classificadas como pesquisa e desenvolvimento experimental ou um desenvolvimento de engenharia. A Lei do Bem só prevê incentivos fiscais para o primeiro caso. A diferença entre as duas classificações está no risco tecnológico envolvido nas atividades. O conceito de desenvolvimento experimental da Lei do Bem está relacionado com trabalhos sistemáticos delineados a partir de conhecimentos pré-existentes, visando a comprovação ou demonstração da viabilidade técnica ou funcional de novos produtos, processos, sistemas e serviços ou, ainda, um evidente aperfeiçoamento dos já produzidos ou estabelecidos. Esta atividade envolve risco tecnológico, pois não necessariamente resultará em sucesso. Um evidente aperfeiçoamento também pode ser considerado nessa classificação, desde que não seja simplesmente uma alteração de layout ou outras atividades de aplicação de conceitos de melhoria e sim um aperfeiçoamento significativo. Alterações óbvias e que não envolvam risco, em virtude dos processos e metodologias utilizados serem conhecidos ou dominados, são considerados como desenvolvimento de engenharia. Ainda que constituam uma novidade para a empresa é necessário evidenciar que houve enfrentamento de barreiras técnicas que foram superadas com as atividades de P&D. Estes desenvolvimentos podem resultar em novos produtos ou processos. Podem, também, ser resultado de pesquisas de mercado ou pesquisas que visam conhecer e detectar melhorias nos produtos e processos. Entretanto, estas atividades não são elegíveis como válidas para justificar os incentivos fiscais da Lei do Bem.
