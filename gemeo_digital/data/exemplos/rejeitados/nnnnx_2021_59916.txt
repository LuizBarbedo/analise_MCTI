PROJETO - NOME: Defense IA
DESCRIÇÂO: "O projeta trata-se do desenvolvimento de uma plataforma de integração dos softwares e soluções da Intelbras.
No ano de 2021 foram iniciados as atividaes de:

Ferramenta gestão de dispositivos:
•	Desenvolvimento de uma ferramenta para emissão de relatórios mais detalhados de dispositivos e atualização em massa de firmware
•	A primeira versão envolvia somente atualização de firmware para gravadores e relatórios destes dispositivos. Agora já é possível realizar a atualização de firmware de controle de acesso também.
•	Está em processo de testes de campo, e realizando algumas melhorias nos relatórios, como mostrar quantidade de canais com gravação, tipo de gravação, entre outros.
•	Espera-se ter uma ferramenta completa de gestão, onde em somente um aplicativo, possa-se monitorar todo o parque de gravadores do cliente e saber status de dispositivos/gravação, controle de firmware, controle de operação na ferramenta, e futuramente poder atualizar a versão de firmware das câmeras conectadas aos gravadores.

Ferramenta de backup
•	Ferramenta para realizar o backup automático das gravações provenientes dos dispositivos conectados ao software;
•	Uma aplicação que utiliza o SDK do software e programada em C#, onde é possível selecionar os canais que deseja realizar o backup;
•	Está em fase de teste de campo com um número limitado de dispositivos (até 200 canais de vídeo);
•	O próximo passo é realizar o aumento na quantidade de dispositivos que possam ser selecionados para realizar o backup, pelo menos até 1000 canais de vídeo.

Integração AMT 8000
•	Por conta do protocolo de recebimento de comandos e envio de eventos ao software ser diferente, a integração nativa desse dispositivo não seria rápida, se fosse feita pelo fornecedor do software.
•	Com isso, foi inicializado o processo de desenvolvimento de um serviço que pudesse se integrar com a central de alarme e o software.
•	Informações técnicas:
o	Baseando-se em um dispositivo já integrado ao sistema, foi desenvolvida uma aplicação em linguagem Go, que traduz os comandos que o software envia para a central, e traduz os eventos que a central envia para o software;
o	Esse serviço de tradução é chamado de middleware;
o	Os serviços tiveram que passar por uma modificação, pois nos testes, foi constatado uma diferença de envio de comandos quando utilizado modo de comunicação via GPRS;
o	O projeto está em fase agora de testes de performance para verificar os limites do sistema

Integração Centrais de Incêndio
•	Utilizando o mesmo conceito do middleware da central de alarme AMT 8000, foi iniciado o desenvolvimento da integração com as centrais de incêndio Intelbras;
•	O projeto consiste em apenas receber os eventos provenientes das zonas da central de incêndio e realizar vinculações através desses eventos;
•	O projeto está em fase final de testes, e logo poderá já ser disponibilizado para o mercado.

Sistema para cadastro de pessoas do controle de acesso
•	O projeto consiste em melhorar o cadastro e gerenciamento de usuários dos controladores de acesso do sistema (tanto usuários fixos quanto visitantes).
•	Para este projeto, foi elaborado toda uma estrutura de backend e frontend com total integração ao software Defense IA, para que sejam realizados os cadastros de pessoas de forma transparente ao usuário final.
•	Já foi realizado todo o desenvolvimento do frontend da aplicação, e o backend para cadastros das pessoas;
•	O projeto está em fase de estruturação do backend para realizar o recebimento de eventos de controle de acesso e ser possível obter relatórios através desses eventos;
•	Após finalização dessa primeira etapa, espera-se poder iniciar o desenvolvimento para gerar credencial do tipo QR Code para visitantes e inicializar a função de antipass-back.

PALAVRAS CHAVE: 
ELEMENTO TECNOLÓGICO: O Defense IA é um software que gerencia de forma unificada equipamentos de segurança eletrônica e faz o videomonitoramento de todo o sistema. O software é constituído por uma operação multiplataforma onde provê aplicações para ambientes Windows, Web e Mobile de forma integrada, sendo capaz de oferecer a compatibilidade com diferentes soluções de equipamentos Intelbras, assim como a possibilidade de integração de dispositivos terceiros na solução. Atualmente representa a única solução de software Intelbras capaz de gerenciar e integrar de forma completa as inteligências de Reconhecimento Facial, Leitura de placas (LPR), análises de vídeo com Inteligência Artificial; produtos de Controle de Acesso, Alarmes e de outras empresas do grupo (como o Horn Speaker da Khomp). Por ser um projeto totalmente novo para empresa ele é considerado inovador.

DESAFIO TECNOLÓGICO: Os maiores desafios são integrar os mais diferentes tipos de dispositivos em uma única plataforma. Isso significa utilizar SDKs e APIs de diversos produtos a fim de estabelecer a comunicação entre eles. Além disso, é necessário também criar toda a lógica por trás da aplicação, desde a interface web (frontend) até o banco de dados (backend).

É um projeto de Natureza de Serviço e não de Processo!

Outro ponto de inovação deste projeto é permitir operar com multiplataformas onde provê aplicações para ambientes Windows, Web e Mobile de forma integrada, sendo capaz de oferecer a compatibilidade com diferentes soluções de equipamentos Intelbras, assim como a possibilidade de integração de dispositivos terceiros na solução.
